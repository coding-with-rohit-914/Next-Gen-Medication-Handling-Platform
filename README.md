### Pharmacy Dispensing System || Python Django
    
### This is a simple Pharmacy Management System programmed using Python Django. 

### The system has 5 types of users are the Administrator, Pharmacist, Doctor, and Receptionist(pharmacyClerk) and Patient.

### This project has user-friendly functionalities.

### python.exe -m pip install --upgrade pip

### Step 1: pip install -r requirements.txt

### Step 2: python manage.py makemigrations

### Step 3: python manage.py migrate (makemigrations)
        
### Step 4: python manage.py runserver (Give id Like eg: 1111, 1234, ....)
